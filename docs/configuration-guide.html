Principais configurações para alteração na infraestrutura Terraform

🐳 Configurações ECS (Elastic Container Service)

Recursos do Container

locals.tf → env_config → container_cpu / container_memory
Desenvolvimento
CPU: 2048 (2 vCPU)
Memory: 317 MB
Produção
CPU: 2048 (2 vCPU)
Memory: 307 MB
⚠️ Importante: Memory deve ser compatível com CPU. Para 2048 CPU, máximo de 4096 MB.

📋 Referência Rápida - Arquivos Principais

Configurações Principais

  • locals.tf - Configurações por ambiente
  • terraform.tfvars - Variáveis desenvolvimento
  • terraform-prod.tfvars - Variáveis produção
  • variables.tf - Definições de variáveis

Scripts Úteis

  • deploy.sh - Deploy automatizado
  • scripts/health-check.sh - Verificação de saúde
  • scripts/backup-report.sh - Relatório de backups

Comandos Essenciais

  • ./deploy.sh dev plan - Planejar dev
  • ./deploy.sh prod apply - Aplicar prod
  • terraform validate - Validar sintaxe
  • terraform output - Ver outputs

Monitoramento

  • CloudWatch Dashboard - BIA-{env}-Dashboard
  • Alarmes - CPU, Memory, RDS
  • Logs - /aws/ecs/bia-{env}
  • Métricas - ECS, ALB, RDS
💡 Dica: Sempre teste alterações no ambiente de desenvolvimento antes de aplicar em produção. Use terraform plan para revisar mudanças antes de aplicar.
# Exemplo de alteração de recursos ECS # Em locals.tf, seção dev ou prod: container_cpu = 4096 # Dobrar CPU (4 vCPU) container_memory = 1024 # Aumentar memória para 1GB # Lembrar: Memory deve ser compatível com CPU # CPU 4096 permite memory até 8192 MB
